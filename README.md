# BookMyStayApp

## Overview

**BookMyStayApp** is a simple Java console application that serves as the entry point for a **Hotel Booking Management System**. It demonstrates the basic structure of a Java program and confirms that the system starts successfully.

## Features

* Application entry point using the `main()` method
* Displays a welcome message
* Confirms successful system initialization

## How to Run

1. Compile the program:

```
javac BookMyStayApp.java
```

2. Run the program:

```
java BookMyStayApp
```

## Output

```
Welcome to the Hotel Booking Management System
System initialized successfully.
```
