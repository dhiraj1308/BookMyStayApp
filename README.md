OverviewThis project simulates a hotel reservation cancellation system. It ensures that when a guest cancels a booking, the room inventory is automatically updated (rolled back) and a history of these actions is maintained.Key FeaturesInventory Management: Tracks available room types (Deluxe, Suite) and updates counts in real-time.LIFO Rollback: Uses a Stack to track cancellations, ensuring the most recent cancellation is at the top of the history.Validation: Prevents errors by checking if a Reservation ID exists before attempting a cancellation.State Consistency: Ensures that removing a booking from the "Active" list and adding it back to "Inventory" happens in sync.How It WorksInitialize: Rooms are added to the RoomInventory.Register: Bookings (e.g., RES-001) are mapped to specific room types.Cancel: When cancelBooking() is called:The system verifies the ID.The room type is identified.The inventory count increases by 1.The ID is pushed to the releasedRoomIds stack for record-keeping.Review: The system displays a LIFO (Last-In, First-Out) history of all successful rollbacks.Quick StartEnsure you have Java installed.Save the code as BookMyStayApp.java.Compile: javac BookMyStayApp.javaRun: java BookMyStayApp
