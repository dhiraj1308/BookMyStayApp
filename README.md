FIFO
The Booking Request System (Version 5.0) is designed to streamline the initial stage of guest reservations by capturing booking intent in a structured, predictable manner. Using First-Come-First-Served (FCFS) logic, this application ensures that all incoming requests are handled with total fairness and transparency. At this stage of the system architecture, the focus is strictly on queuing the guest's name and their preferred room type—such as Single, Double, or Suite—without yet performing final room allocation or inventory updates. This makes it a robust foundational tool for managing high-traffic reception workflows where "intent to book" must be recorded before confirmation.
Technically, the system is built on a modular Java architecture consisting of three core components: the Reservation data model, the BookingRequestQueue manager, and a demonstration driver class. By leveraging Java’s Queue interface implemented via a LinkedList, the system achieves high efficiency for both adding requests and retrieving them. This ensures that as the volume of guest requests grows, the software remains responsive and strictly maintains the FIFO (First-In-First-Out) sequence. The code is fully documented with Javadoc comments to ensure maintainability and clarity for future developers working on room allocation modules.
